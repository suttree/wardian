# The Living Cabinet

A long-term design project exploring hydroponics, museum displays, and slow technology.

The Living Cabinet is not intended to be a hydroponic garden, kitchen appliance, or productivity device. It is a domestic museum exhibit: a carefully lit place where living specimens are selected, presented, and observed over time.

The project draws from Victorian Wardian cases, natural history museums, botanical illustration, apothecary jars, library displays, scientific laboratories, and quiet contemplative technology.

## Core Idea

The project is about curation rather than cultivation.

Each vessel is a single exhibit. The plant, roots, water, light, label, and surrounding materials should all feel deliberate. Nothing should look accidental, improvised, or overly electronic.

The display should invite slow observation.

## First Milestone

The first milestone is not to build a cabinet.

It is to create one beautiful, stable, photographable specimen display that still looks good after 30 days.

Version 1 should be:

- one shelf
- one glass vessel
- one light
- one plant
- passive hydroponics
- no cabinet
- no pumps
- no hidden complexity unless it improves the display

## Design North Star

The best version of this project should feel less like owning a plant system and more like being the custodian of a small living collection.
